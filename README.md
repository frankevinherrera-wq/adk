# ADK — Agentic Development Kit

**A reusable development toolkit for AI coding agents.**

ADK provides reusable workflows, skills, agents, templates and project configurations to help developers build software with AI coding agents in a structured and consistent way.

## Vision

Make structured, practical and adaptable AI-assisted software development accessible to individual developers and teams.

## Problem

AI coding agents can generate code quickly, but development workflows often lack consistency in project discovery, planning, documentation, implementation and verification.

ADK aims to provide a reusable workflow that reduces unnecessary planning, preserves important decisions and encourages continuous implementation.

## Core principles

- **Progressive documentation:** document what the project actually needs.
- **Incremental development:** move from ideas to working software in small iterations.
- **Reusable workflows:** share development procedures across projects.
- **Human control:** require approval for important decisions and sensitive actions.
- **Modular architecture:** separate the core methodology from tool-specific integrations.

## Planned capabilities

- Reusable agent skills and instructions.
- Specialized AI coding agents.
- Development workflow commands.
- Project profiles and documentation templates.
- Installation and configuration CLI.
- Integrations for multiple AI coding environments.

## Initial development

ADK is under active development.

The first MVP will prioritize OpenCode integration, a controlled workflow and a documentation system using adaptive project profiles.

Additional coding-agent integrations will be introduced incrementally.
